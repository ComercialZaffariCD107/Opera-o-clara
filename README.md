# Operação Clara — Relatórios

Versão estática pronta para publicação no **GitHub Pages**.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `operacao-clara`).
2. Envie para a raiz do repositório:
   - `index.html`
   - `.nojekyll`
   - `README.md`
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`.
6. Clique em **Save**.

O site é totalmente estático e roda direto no navegador. Os dados/importações usados pela aplicação permanecem no lado do cliente; o GitHub Pages não fornece banco de dados ou backend.
